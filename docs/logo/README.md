# Logo — Kolorowe Sąsiedztwo

## Koncepcja

Logo oparte na wizualizacji projektu:
- **3 domy szeregowe** — symbol sąsiedztwa i powtarzalności
- **Strome dwuspadowe dachy** — charakterystyczna sylwetka z wizualizacji
- **3 kolory pastelowych elewacji** — niebieski, różowy, żółty (jak na renderze)
- **Cienkie czarne linie** — minimalistyczny styl architektoniczny

## Paleta kolorów

| Kolor | HEX | Zastosowanie |
|-------|-----|--------------|
| Niebieski | `#9eb9c8` | Elewacja dom 1 |
| Różowy | `#c9a8a8` | Elewacja dom 2 |
| Żółty | `#d4c48a` | Elewacja dom 3 |
| Ciemny | `#2c2c2c` | Obrysy, tekst |

## Jak użyć

- **Plansza tytułowa A3:** `kolorowe-sasiedztwo-tytul.png`
- **Portfolio / Word:** `kolorowe-sasiedztwo-logo.png`
- **Mała ikona na planszach:** `kolorowe-sasiedztwo-icon.png`

Otwórz plik `.svg` w Inkscape lub przeglądarce, aby edytować kolory.
