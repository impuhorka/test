# Inventaryzacja miasta Wojnicz

Repozytorium zawiera opis części opisowej pracy z inventaryzacji miasta — praktyki architektonicznej dotyczącej miasta **Wojnicz** (woj. małopolskie, powiat tarnowski).

## Dokument

- [`docs/wojnicz-inventaryzacja-miasta.pdf`](docs/wojnicz-inventaryzacja-miasta.pdf) — **PDF do wydruku** (19 stron A4, język polski)
- [`docs/wojnicz-inventaryzacja-miasta.md`](docs/wojnicz-inventaryzacja-miasta.md) — źródło Markdown

### Regeneracja PDF

```bash
python3 scripts/md-to-pdf.py docs/wojnicz-inventaryzacja-miasta.md
```

## Zakres opracowania

Dokument obejmuje wymagane rozdziały:

1. Wstęp
2. Rys historyczny miasta *(obowiązkowy)*
3. Analiza rozwoju historycznego
4. Środowisko kulturowe
5. Układ zabudowy *(obowiązkowy)*
6. Analiza przestrzenna *(obowiązkowy)*
7. Analiza funkcjonalna *(obowiązkowy)*
8. Charakter miasta *(obowiązkowy)*
9. Układ komunikacyjny *(obowiązkowy)*
10. Uwarunkowania przyrodnicze *(obowiązkowy)*
11. Demografia i struktura ludności *(obowiązkowy)*
12. Wywiad z mieszkańcami *(obowiązkowy — pytania + tabela do uzupełnienia w terenie)*
13. Podsumowanie i wnioski

## Do uzupełnienia w terenie

- Wyniki wywiadów z mieszkańcami (rozdział 12)
- Dokumentacja fotograficzna i mapy
- Pomiary terenowe
